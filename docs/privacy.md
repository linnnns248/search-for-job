# 公开发布与隐私规则

GitHub Pages 是公开页面，发布后的 HTML、JavaScript、JSON 和下载文件均可被任何访问者读取。

## 允许发布

- 公司及公开公司规模。
- 公开岗位名称与岗位描述。
- 公开薪资信息。
- 数据来源名称及公开岗位链接。
- 首次发现、最后发现和公开状态。

## 禁止进入 Git 或构建产物

- Boss 账号、密码、Cookie、浏览器登录状态。
- GitHub Token、SSH 私钥、API 密钥。
- 个人简历、电话号码、邮箱、住址等个人信息。
- 求职备注、联系人、投递状态。
- 岗位与个人简历的分析结果。
- 包含登录态或个人标识的原始页面快照。

本地敏感文件只能存放在 `.gitignore` 已排除的目录中。提交前必须检查暂存文件；自动采集器只能输出经过字段白名单过滤的数据。

## Boss 登录状态

- 扩展只在 `zhipin.com` 页面运行；登录状态仍由用户的普通 Chrome 管理，不复制 Cookie。
- 页面快照只在内存中发送到 `127.0.0.1` 接收器解析，不保存原始 HTML。
- 扩展令牌只保存在 Chrome 本地扩展存储和 `.collector/extension-token`，不得提交。
- 账号、密码和验证码由用户直接在 Boss 页面输入，采集器不读取、不记录。
- 登录或安全验证未完成时立即停止，不实现绕过机制。
- 换电脑时重新安装扩展并登录，不通过 Git、网盘或文件传输迁移浏览器资料。
