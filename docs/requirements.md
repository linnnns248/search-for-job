# 产品需求

## 目标

在一个公开、跨设备访问的网页中，结构化汇总成都产品经理岗位。采集在用户本地电脑完成，经过清洗的公开岗位数据推送到 GitHub，随后由 GitHub Pages 发布。

## 已确认范围

- 岗位方向：产品经理、高级产品经理、策略产品经理、商业产品经理、平台产品经理、数据产品经理、用户产品经理、增长产品经理、AI 产品经理。
- 默认城市：成都，可配置扩展。
- 默认公司规模：100 人以上，可配置调整。
- 求职类型：全职，可配置调整。
- 学历要求：本科及以上，可配置调整。
- 默认薪资：月薪下限 10K 及以上，可配置调整。
- 来源：Boss 直聘和用户提供的公司官网。
- 计划频率：中国法定工作日北京时间 23:00。
- 首次配置完成后支持立即执行一次。
- 页面支持任意设备访问、筛选、排序、查看详情和数据下载。
- 可见字段：公司、公司规模、岗位名称、岗位描述、薪资、数据来源、岗位链接。

## 当前不包含

- 自动投递与投递状态管理。
- 私人简历、个人备注及简历分析结果公开发布。
- 绕过验证码或招聘平台安全验证。
- 伪造浏览器指纹、破解限流或其他规避平台安全机制的行为。
- 服务端数据库和登录体系。

## 版本目标

- `v0.1.0`：公开页面、示例数据、筛选和下载。
- `v0.2.0`：本地 Boss 采集。
- `v0.3.0`：公司官网采集框架。
- `v0.4.0`：采集结果自动提交、GitHub 推送和异常恢复。
- `v1.0.0`：稳定日常使用版本。
