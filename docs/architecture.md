# 技术架构

## 当前架构

```text
public/data/jobs.json
        ↓
React + TypeScript 静态页面
        ↓
Vite 构建
        ↓
GitHub Actions
        ↓
GitHub Pages
```

页面没有服务端运行时，也没有数据库。所有随页面发布的数据均视为公开信息。

## 后续采集架构

```text
本地主采集电脑
  ├─ 专用浏览器与 Boss 登录状态（永不提交）
  ├─ Boss 数据源适配器
  ├─ 公司官网适配器
  ├─ 标准化、去重和状态判断
  └─ 生成 public/data/jobs.json
              ↓
        Git commit / push
              ↓
        GitHub Pages 更新
```

采集端与页面通过版本化 JSON 协议解耦。未来更换采集电脑时，只需克隆仓库、安装采集端并重新登录 Boss。

## 扩展边界

- 城市、薪资、公司规模、关键词、计划时间由配置定义，不写死在采集器。
- 新官网通过统一数据源适配器接入。
- 岗位使用稳定 ID 与来源 ID 做同源去重，跨来源使用公司、岗位、城市和描述相似度保守合并。
- 只有来源本次成功扫描后，“未发现”才可用于判断疑似下架。
- 如未来增加私人简历分析，应使用独立的受保护服务，不能把简历或分析结果发布到 Pages。
