# 公司官网来源清单

公司官网配置位于 `config/official-sites.json`。当前共登记 46 个用户提供的官方招聘入口，所有来源默认关闭，完成公司规模、岗位字段和采集稳定性验证后再逐个启用。

## 当前分类

| 初步类型 | 数量 | 说明 |
| --- | ---: | --- |
| 普通页面选择器 | 9 | 页面能直接返回部分岗位内容，仍需逐站配置列表与详情选择器 |
| Moka | 4 | 可复用 Moka 适配器，需确认租户、招聘类型和分页接口 |
| 北森 / Zhiye | 3 | 可复用 Zhiye 适配器，需确认站点模板和成都筛选参数 |
| 专用动态站点 | 23 | 页面依赖 JavaScript 或公开接口，需要站点专用适配器 |
| 待确认 | 7 | 当前访问超时、重定向异常或无法判断招聘系统 |

这些数量代表技术接入类型，不代表已经启用，也不代表目前一定存在符合条件的成都产品经理岗位。

## 启用门槛

单个来源只有同时满足以下条件才可把 `enabled` 改为 `true`：

- 招聘链接仍有效且无需登录。
- 公司规模已经确认达到当前配置的 100 人以上，并记录公开依据。
- 适配器能稳定发现列表、读取详情和保留官网岗位链接。
- 能判断岗位城市、名称、学历和求职类型。
- 已披露薪资时可以正确解析；未披露薪资按 `publicationPolicy` 处理。
- 空结果、结构变化或网络失败不会覆盖已有岗位。
- 对应解析器有固定样例和自动测试。

## 缺失字段口径

`publicationPolicy` 当前设置为：

- 官网未披露薪资：允许保留，页面显示“未披露”，不推测薪资。
- 官网未披露学历：不发布。
- 官网未披露求职类型：不发布。

这些规则均为配置项，后续调整不需要重写站点适配器。

## 首个验证站点

云览科技招聘页可以直接读取岗位列表、薪资、成都地点和详情页。详情页包含“本科及以上”等要求，适合作为首个普通页面适配器样板。当前仍保持关闭，待公司规模依据和列表/详情合并逻辑完成后再启用发布。

## 安全边界

- 只接受无账号信息的 HTTPS 公开链接。
- 未验证来源不能启用。
- 不提交 Cookie、账号、验证码、原始登录页面或个人信息。
- 不绕过验证码、访问限制或招聘站安全策略。
